SWAP CALENDAR v6

v5の主な変更:
- 濃紺カード内の数値を白に変更し、コントラストを改善
- 月間・年間の実績集計から未来日を除外
- 月別一覧で過去月の実績、当月の実績＋残日予測、未来月の予測を区別
- 決済時の累積スワップから、保有中に日次計上済みの推計分を差し引いて実績へ反映（概算重複防止）
- 月間予測は今日以降の残日だけを計算
- 既存の保存キー swap-calendar-v3 を維持し、既存ブラウザデータとの互換性を優先

重要:
- これは個人管理用の試作版です。FX会社との自動接続はありません。
- スワップ単価・付与日数・決済損益は取引報告書と照合してください。
- バックアップJSONを必ず保管してください。
- 初期保有建玉の累積スワップは開始時点のスナップショットであり、過去の月別実績を自動で復元するものではありません。


v6の注意:
- 決済時の重複調整は、登録済みの日次単価・付与日倍率を使った推計です。過去の単価履歴が未登録の場合、調整額の精度は下がります。
- 決済時の累積スワップは、FX会社の決済明細に表示された対象数量分の実額を入力してください。
