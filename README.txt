SWAP CALENDAR v14

【v9の修正内容】
・カレンダーを月〜金の5列表示に（v8の説明どおりに実装）。土日に金額・設定がある日は、カレンダー下のボタンで選択可能
・付与日数の既定を「土日0日／水曜3日／その他1日」に変更。設定タブで通貨ペア別に3日付与の曜日を変更可。日別に登録した付与日数・実績は従来どおり優先
・付与日数の通貨ペア選択が先頭に戻る不具合、日別入力フォームが毎回初期化される不具合を修正
・決済履歴を削除しても保有数量が戻らない不具合を修正（決済履歴と決済取引を連動して削除）
・「全データを削除」後にエラーで動かなくなる不具合を修正
・バックアップ復元時に古い形式のデータでエラーになる不具合を修正。保存データが壊れていた場合は上書きせず退避
・タブが固定ヘッダーに隠れる問題を修正（ヘッダーはスクロールで流れ、タブのみ固定）
・集計「通算」で通貨ペア別・口座別が0円になる問題を修正
・ヘッダーに月末見込み（実績＋残日予測）を追加。「今年の実現＋未決済損益」を実際の計算内容に合わせ「今年の実績損益」に変更
・登録済みスワップ単価を個別に削除可能に
・iPhoneで入力時に画面が拡大される問題を修正
・オフライン動作とアプリ更新の反映を修正、ホーム画面用PNGアイコンを追加

・スワップ実績は「1付与日分」として扱い、付与日数を掛けて日額に反映（実績入力日も付与日数が効く）
・予定日の「予」をマスの日付横の小バッジにし、金額が折り返さないよう修正

・古い画面が残る問題の対策：sw.jsの更新確認を強化（ブラウザのHTTPキャッシュを使わない）。画面下部に版数を表示

・予定日（明日以降）の金額はカレンダーに表示せず、日付の長押しで予定額・内訳を表示（過去日も長押しで内訳）
・日別の内訳は、スワップ・損益が発生している通貨ペアだけをコンパクトに表示

・取引タブの「現在の保有数量」に［修正］ボタンを追加。修正後の数量、または増減（マイナス可）を入力すると、差分が「調整」として取引履歴に記録される（損益は発生しない）
・取引登録の数量にマイナス入力を許可（±ボタン付き）。取引区分に「調整」を追加。保有数量がマイナスになる入力は拒否
・取引日の入力欄が数量欄に重なる表示崩れを修正、保有数量の表示をコンパクト化

・［修正］内で、初期平均レートと初期累積スワップも修正可能に（初期建玉のある通貨ペアのみ）

・ホーム画面用PNGアイコンを追加（iPhoneのホーム画面に表示されるようになります）
・バックアップ未保存／30日以上経過で、画面上部に警告バーを表示。ブラウザの自動削除を避ける永続保存の申請も追加
・スワップ実績の入力に「付与日数分の合計額として入力（掛け算しない）」を追加（水曜に3日分の合計を入れる場合に使用）
・決済日までのスワップ控除で、実績入力がある日は予測値ではなく実績を使用（二重計上の誤差を解消）
・取引登録に「約定レート（任意）」を追加。設定タブの現在レートから、保有数量ごとの評価損益と合計を取引タブに表示
・取引履歴・登録済み単価を編集可能に。口座・通貨ペア・現在レートを削除可能に（使用中のものは削除不可）
・土日は付与されないため、土日用の表示ボタンを廃止

【配置】
※index.html だけでなく sw.js も必ず同時に差し替えてください
index.html / sw.js / manifest.webmanifest / icon.svg / PNGアイコン を同じフォルダに置いてください。

【データ】
保存データキーは swap-calendar-v3 を継続使用します。既存データはそのまま引き継がれます。
更新前にアプリ内のJSONバックアップを保存してください。
