SWAP CALENDAR v19

【v19の変更】
・画面上部を「スワップ／決済益／合算」の3つに分けて表示（当月＋今年）。カレンダーのマスにも、スワップに加えて決済益（青文字「決」）を表示。日別の詳細・集計も同じ3区分
・「決済益」＝為替差損益＋決済時のスワップ調整＋手数料・その他。「スワップ」＝日次のスワップ
・通貨ペアの入力を選択式に変更（手動レート・通貨ペアの追加）。主要43ペア＋18通貨の組み合わせから選べる
・レートの自動取得を、登録中の全通貨ペア・追加した対象ペア・登録済みレートの全てに適用。「自動取得の対象に追加」で対象を増やせる。取得できないペアはクロス計算
・自動取得の最終結果（成功／失敗理由）を設定タブに常時表示
・全体をコンパクト化（余白・文字サイズ・ヘッダー）し、配色を整理（スワップ＝緑、決済益＝青、合算＝金、赤＝マイナス）。タブ上の余白を解消

（以下はv18の内容）SWAP CALENDAR v18

【v18の変更】
・レート：配信されない通貨ペア（CHF/TRYなど）を、取得できた別のペアから自動でクロス計算（例：EUR/TRY ÷ EUR/CHF。最も差（スプレッド）が小さい経路を採用）。登録レート一覧に「クロス計算」と表示
・手動レートの通貨ペアを自由入力に変更（登録していない通貨ペアも入力可）。登録レートの一覧表示をコンパクト化
・決済損益：「過去分の記録のみ」を追加。保有数量がない過去の決済でも、為替差損益とスワップを登録可能（数量は空欄可）
・集計：「実現損益の内訳」を追加。スワップ（日次／決済時の調整）と為替差損益・手数料等を別々に表示。月別の内訳、通貨ペア別・FX会社別もスワップと為替等を分けて表示
・決済履歴：為替差損益とスワップ（蓄積）を別行で表示

（以下はv17の内容）SWAP CALENDAR v17

【v17の変更】
・取引タブの各建玉に、平均建値・現在レート（売りはAsk／買いはBid）・評価損益を表示
・［修正］から平均建値を直接入力可能（売り・買いの建玉ごと、初期建玉の有無に関係なく）。「自動計算に戻す」で初期建玉と約定レートからの自動計算に戻せる

（以下はv16の内容）SWAP CALENDAR v16（v15の確認・改良）

【v16の変更】
・レート自動取得：取得後の再描画を安全化（入力中・編集中は画面を作り直さない）。通信不可時のメッセージを分かりやすく変更
・「手動レートが必要」な通貨ペアを、実際に保有している通貨ペアと円換算に必要なペアから判定して表示
・評価損益が出せない建玉に、理由（例：TRY/JPYの現在レート未登録）を表示。評価損益合計に自動取得時刻を表示
・自動保存：毎日の初回起動時に自動でスナップショットを保存（直近8件）。設定タブから復元可能。バックアップ復元・全データ削除の直前にも「操作前」を自動保存
・カレンダーに［今日］ボタンを追加
・保存データキー swap-calendar-v3 は変更なし

（以下はv15の内容）SWAP CALENDAR v15（v14を基準にしたレート機能改修）

【今回の変更】
・Live-Ratesの無料REST配信（/rates）からBid/Askを取得する機能を追加
・無料枠（1時間3回/IP）を超えないよう、前回試行から20分以上経過した場合のみ自動取得
・手動取得ボタンを追加
・通貨ペアごとのBid/Ask、取得元、取得時刻を保存・表示
・売り建玉はAsk、買い建玉はBidを使って評価損益を計算
・損益通貨からJPYへの換算は、損益がプラスならBid、マイナスならAskを優先
・未対応ペアや取得失敗時は既存レートを保持し、エラーを表示
・従来の単一レート（value）も互換維持。自動配信にないペアは手動仲値で評価

【重要な制約】
・Live-Ratesはヒロセ通商の公式レートではなく参考配信。価格差・更新遅延・配信対象外のペアがあり得る
・無料枠は1時間3回/IP。20分間隔は上限を避けるための設計で、連続リアルタイム配信ではない
・無料データの商用利用・再配信条件は別途確認が必要。公開アプリの収益化前にライセンスを確認すること
・クロス円換算に必要なTRY/JPY等が配信にない場合、評価損益は計算不可（ゼロ扱いせず未計算）
・APIのCORS制限によりiPhone Safariから直接取得できない場合がある。その場合は中継サーバー等が必要

【データ保護】
・保存キー swap-calendar-v3 は変更していません
・既存データ構造・dailyEntries・取引・決済・付与日設定を保持
・自動取得はquotesとquoteFetchのみを更新。取引履歴や日別実績は変更しません
・公開前にJSONバックアップを保存してください
