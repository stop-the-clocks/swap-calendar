SWAP CALENDAR v5 (移行・予測改善版)

主な機能
- 複数FX会社・同一会社の複数口座を、口座名ごとに分けて管理
- 初期10通貨ペア＋任意の通貨ペア追加
- 建玉・新規/決済履歴、決済損益、スワップ単価履歴
- 日別カレンダー、月別・年別・通算集計
- 日次スワップ見込み、選択月の見込み、今後365日の見込み
- 証拠金情報の手入力と維持率等の表示
- JSONバックアップ／復元、取引履歴CSV出力

データ移行
- 新しい保存領域(swap-calendar-v3)が空の場合、旧版(swap-calendar-v1)の取引・単価・履歴データを読み込み、新しい保存領域へコピーします。
- 旧版のJSONバックアップは必ず保管してください。初回起動後にデータ件数・建玉数量を確認し、再度JSONバックアップしてください。

スワップ見込みの前提
- 1付与日あたりの金額は、保有数量と登録済み単価から試算します。
- 月間は選択月、年間は今日から365日を対象に、土日を原則0日として平日を1付与日で計算します。
- 登録済みの通貨ペア別付与日倍率は反映します。
- 祝日・臨時の付与日変更・将来の単価変更・口座ごとの特殊ルールは自動取得しません。必ず概算として扱ってください。

注意
- FX会社口座とのAPI自動連携・自動レート取得は未実装です。
- 実運用前に、建玉数量・スワップ・決済損益・証拠金表示をFX会社の実績と照合してください。
- データは利用中のブラウザ内に保存されます。定期的にJSONバックアップしてください。
