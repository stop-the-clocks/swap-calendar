SWAP CALENDAR v23

【v23の変更】
・レート画面の読み取りを数字の形で判別する方式に変更（文字認識に頼らないため、桁の欠けや5↔9などの読み違いが起きにくい）。別の日のスクリーンショットでも全行一致を確認。通貨ペア名のみ文字認識を使用
・証拠金画面の読み取りを改善：「円」の文字が数字として混ざらないよう右端を除いて認識し、レバレッジのみ全幅で再認識。万一余分な数字が付いても、整合性（預託＋評価損益＝有効証拠金／有効比率／発注可能額／出金可能額／評価損益＝ポジション損益＋未実現スワップ）から自動修復
・ポジションロック（ヒロセ通商）対応：「ロック以外」の評価損益・ポジション損益・未実現スワップも取り込み。ロックがある場合のみ、設定タブとホーム上部に注記を表示
・表示の調整：金額の途中改行（「-」と数字の分離）を解消、スワップ見込みを3列に整理、集計・設定タブではヘッダーを圧縮、単価一覧の行を整理、色の統一（スワップ＝緑／決済益＝青）、レート入力欄は通貨ペアごとの桁数で表示
・アイコン（青色のSWAP CALENDAR画像）・manifest・sw.js はお持ちの最新版を採用。アイコンはキャッシュ更新用に ?v=23 を付与

【アイコンについて】
新しい青色のSWAP CALENDAR画像をアイコンに採用。
index.html / sw.js / manifest.webmanifest / icon.svg / icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png をGitHubリポジトリのルートへ上書きしてください。
保存キー swap-calendar-v3 は変更していません。
ホーム画面のアイコンが変わらない場合は、バックアップ確認後にホーム画面のショートカットのみ削除し、Safariから再度ホーム画面に追加してください。ブラウザのWebサイトデータは削除しないでください。

（以下はv22の内容）SWAP CALENDAR v22

【v22の変更】
・ホーム画面の上部に「有効比率／ポジション損益／未決済スワップ／差引益（損益＋スワップ）」を表示（証拠金画面の取り込み値）。有効比率はアラート基準で色分け（緑＝アラート水準以上、黄＝150%以上、赤＝それ未満）

・通貨ペアの並べ替え：設定タブの通貨ペア管理に↑↓（取引・集計・選択肢の並びに反映）。登録レートも↑↓で並べ替え可能。画像から取り込むと、画像と同じ並びで登録

（以下はv20の内容）SWAP CALENDAR v20

【v20の変更】
・画像から取り込み（設定タブ）：証拠金画面・レート画面のスクリーンショットを選ぶと、端末内で文字認識（OCR）して証拠金と現在レート（Bid/Ask）を読み取り。確認・修正のうえ反映。読み取れない場合は、画像の文字を長押しコピーして貼り付け取り込みも可能
・CHF/TRYなど自動配信にないペア：取り込んだ/手入力したレートを土台に、配信されているペアと組み合わせて自動で再計算（クロス計算）。古い脚がある場合は登録レートに「最古の脚◯時間前」と表示。各レートに取得からの経過時間も表示
・保存：登録・変更のたびに「保存しました」を表示。日別実績（スワップ・為替差損益等）をCSVで保存／読込。保存件数と永続化状況を設定タブに表示
・証拠金：発注可能額・出金可能額・アラート/ロスカット基準額・ポジション損益・未実現スワップも保存して表示

（以下はv19の内容）SWAP CALENDAR v19

【v19の変更】
・画面上部を「スワップ／決済益／合算」の3つに分けて表示（当月＋今年）。カレンダーのマスにも、スワップに加えて決済益（青文字「決」）を表示。日別の詳細・集計も同じ3区分
・「決済益」＝為替差損益＋決済時のスワップ調整＋手数料・その他。「スワップ」＝日次のスワップ
・通貨ペアの入力を選択式に変更（手動レート・通貨ペアの追加）。主要43ペア＋18通貨の組み合わせから選べる
・レートの自動取得を、登録中の全通貨ペア・追加した対象ペア・登録済みレートの全てに適用。「自動取得の対象に追加」で対象を増やせる。取得できないペアはクロス計算
・自動取得の最終結果（成功／失敗理由）を設定タブに常時表示
・全体をコンパクト化（余白・文字サイズ・ヘッダー）し、配色を整理（スワップ＝緑、決済益＝青、合算＝金、赤＝マイナス）。タブ上の余白を解消

（以下はv18の内容）SWAP CALENDAR v18

【v18の変更】
・レート：配信されない通貨ペア（CHF/TRYなど）を、取得できた別のペアから自動でクロス計算（例：EUR/TRY ÷ EUR/CHF。最も差（スプレッド）が小さい経路を採用）。登録レート一覧に「クロス計算」と表示
・手動レートの通貨ペアを自由入力に変更（登録していない通貨ペアも入力可）。登録レートの一覧表示をコンパクト化
・決済損益：「過去分の記録のみ」を追加。保有数量がない過去の決済でも、為替差損益とスワップを登録可能（数量は空欄可）
・集計：「実現損益の内訳」を追加。スワップ（日次／決済時の調整）と為替差損益・手数料等を別々に表示。月別の内訳、通貨ペア別・FX会社別もスワップと為替等を分けて表示
・決済履歴：為替差損益とスワップ（蓄積）を別行で表示

（以下はv15の内容）SWAP CALENDAR v15（v14を基準にしたレート機能改修）

【今回の変更】
・Live-Ratesの無料REST配信（/rates）からBid/Askを取得する機能を追加
・無料枠（1時間3回/IP）を超えないよう、前回試行から20分以上経過した場合のみ自動取得
・手動取得ボタンを追加
・通貨ペアごとのBid/Ask、取得元、取得時刻を保存・表示
・売り建玉はAsk、買い建玉はBidを使って評価損益を計算
・損益通貨からJPYへの換算は、損益がプラスならBid、マイナスならAskを優先
・未対応ペアや取得失敗時は既存レートを保持し、エラーを表示
・従来の単一レート（value）も互換維持。自動配信にないペアは手動仲値で評価

【重要な制約】
・Live-Ratesはヒロセ通商の公式レートではなく参考配信。価格差・更新遅延・配信対象外のペアがあり得る
・無料枠は1時間3回/IP。20分間隔は上限を避けるための設計で、連続リアルタイム配信ではない
・無料データの商用利用・再配信条件は別途確認が必要。公開アプリの収益化前にライセンスを確認すること
・クロス円換算に必要なTRY/JPY等が配信にない場合、評価損益は計算不可（ゼロ扱いせず未計算）
・APIのCORS制限によりiPhone Safariから直接取得できない場合がある。その場合は中継サーバー等が必要

【データ保護】
・保存キー swap-calendar-v3 は変更していません
・既存データ構造・dailyEntries・取引・決済・付与日設定を保持
・自動取得はquotesとquoteFetchのみを更新。取引履歴や日別実績は変更しません
・公開前にJSONバックアップを保存してください
