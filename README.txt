SWAP CALENDAR v8
日別スワップ実績の直接入力（通貨ペア単位）、日別の為替差損益・手数料・その他損益入力、カレンダー合計への反映を追加。実績入力した通貨ペア・日付は予測額を置き換えます。正負で色分けし、実績入力日は「実績」と表示します。

更新前にアプリ内のJSONバックアップを保存してください。GitHub Pagesの index.html と sw.js を差し替えます。保存データはブラウザ内に残ります（localStorageキーはswap-calendar-v3を維持）。
注意：日別実績は通貨ペア単位の合計額です。口座別配賦は次段階の拡張項目です。入力内容はFX会社の取引報告書と照合してください。
