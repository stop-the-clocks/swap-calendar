# SWAP CALENDAR

## 起動
- `index.html` をブラウザで開くと基本機能を試せます。
- iPhoneのホーム画面に追加してPWAとして使うには、HTTPS対応のWebホスティングにこのフォルダ内の4ファイルを配置してください。
- 公開URLをiPhoneのSafariで開き、「共有」→「ホーム画面に追加」を選びます。

## 機能
- FX会社・通貨ペアの追加
- 新規・決済履歴から保有数量を自動計算
- FX会社・通貨ペア・売買別のスワップ単価履歴
- 日付・通貨ペア別の付与日数（0～6日）
- 日別カレンダー、月別・年間・通算の集計
- 決済時の為替差損益と蓄積スワップの合算
- JSONバックアップ・復元、取引履歴CSV出力

## 注意
- データはブラウザのlocalStorageに保存されます。ブラウザデータの消去や端末故障に備え、定期的にJSONバックアップを保存してください。
- 口座との自動接続やFX会社の公式付与日カレンダー連携は未実装です。
- スワップ単価・付与日数は手動入力です。通貨ペア・FX会社ごとに実際の付与条件を確認してください。
- 取引履歴は取引日単位で管理します。ロールオーバー時刻をまたぐ取引は、実際の付与対象日を確認して入力してください。
- 決済登録時は、決済数量分の決済取引履歴も自動で追加されます。決済時の蓄積スワップを入力する場合、日別スワップの計上と二重計上しないよう、集計上は為替差損益とスワップを別区分で確認してください。
- 本アプリは投資判断・税務計算を行うものではありません。
