SWAP CALENDAR v11
v10の機能を引き継いだ更新版です。カレンダーは平日（月〜金）の5列表示で、土日を非表示にし、平日の表示領域を広く使います。日別スワップ実績・その他損益の直接入力、予測/実績/差額表示、付与日数を反映した予測計算を維持しています。

データ保存キー swap-calendar-v3 は変更していません。既存データを引き継ぐ設計です。更新前に必ずアプリ内のJSONバックアップを保存してください。更新後は保有建玉・スワップ単価・証拠金・日別実績が残っていることを確認してください。

GitHub PagesではZIPを解凍し、index.html と sw.js をリポジトリ直下で差し替えてください。manifest.webmanifest と icon.svg は変更ありません。
